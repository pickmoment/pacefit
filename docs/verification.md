# v0.3.5 검증 기록

검증일: 2026-11-01 (Asia/Seoul)

## 0.3.5 현재 프리셋 표시

영상 위 배속 버튼과 1.5초 알림에 `A · 1.5×`, `B · 2.3×`처럼 선택한 프리셋을 함께 표시합니다. 팝업 제목과 스크린리더의 배속 안내에도 현재 A·B를 포함합니다. 기존 확장 검사와 배속 유지 검사에서 초기 A 표시, 속도 조절 후 표시와 B 전환 후 버튼·알림 표시를 확인합니다.

## 0.3.4 조절 가능한 A/B 프리셋

A·B 두 프리셋을 독립적으로 저장하며, 선택된 프리셋에서 배속을 조절하면 그 프리셋만 갱신합니다. `\`와 전환 버튼은 선택된 프리셋을 A ↔ B로 바꾸고 저장된 속도를 적용합니다. 팝업과 영상 위 메뉴 모두 A·B 선택 버튼과 선택 상태를 표시합니다. 최초 설치 기본값은 A 1배속·B 2배속이며, 이전 버전에서는 저장한 현재 배속을 A로 이전합니다.

단위 검사는 프리셋별 조절·반복 왕복·같은 값의 A/B 구분·단축키 간격 조절·설정 이전을 확인합니다. 브라우저 검사는 팝업에서 A/B를 각각 조절한 뒤 전환, 영상 전환 후 프리셋 복원, 단축키로 B 조절, 영상 위 버튼으로 A 조절과 왕복을 확인합니다. 설정 저장은 변경한 프리셋만 갱신해 다른 프리셋을 덮어쓰지 않습니다. 아래 0.3.3의 직전 속도 방식은 해당 버전의 과거 기록이며 A/B 프리셋으로 대체했습니다.

## 0.3.3 두 속도 전환

`\` 단축키와 팝업·영상 위 전환 버튼은 현재 배속과 직전 배속을 교환합니다. 1.5배속에서 2배속으로 바꾸면 1.5 ↔ 2배속으로 왕복하며, 전환된 현재 배속과 직전 배속을 함께 저장합니다. 다음 영상에도 배속 유지를 켠 상태에서 영상이 바뀌어도 이 쌍을 사용할 수 있습니다. 같은 값 재선택이나 조절 한계에서는 직전 배속을 덮어쓰지 않습니다.

단위 검사에서 반복 왕복, 같은 값 재선택, 최댓값 조절, 초기 전환 대상과 기존 설정의 이전을 확인합니다. 실제 확장 검사와 배속 유지 검사에서 팝업·단축키 전환, 키 반복 방지, 입력란 제외와 다음 영상으로 이동한 뒤의 왕복을 확인합니다. 아래 0.3.1의 임시 1배속 동작은 해당 버전의 과거 기록이며 0.3.3에서는 두 속도 전환으로 대체했습니다.

## 0.3.2 영상 시작 배속 알림

영상의 메타데이터가 준비되고 플레이어가 화면에 보이면 기존 1.5초 배속 알림을 한 번 표시합니다. 다음 영상 전환에서도 새로 적용한 배속을 표시하며, 광고 중이나 예외 사이트에서는 표시하지 않습니다. 같은 영상의 일시정지·재생은 알림을 반복하지 않습니다. 마우스를 올려 컨트롤이 보일 때는 기존처럼 알림을 겹치지 않습니다.

`scripts/retention-check.cjs`에서 처음 열린 영상의 1배속 표시·자동 숨김, 일시정지 후 재생 시 반복 방지, 다음 영상의 저장된 2배속 표시·자동 숨김을 확인합니다.

## 0.3.1 배속 유지 회귀 검사

실제 재생 가능한 미디어와 임시 Chrome에 설치한 확장으로 `scripts/retention-check.cjs`를 실행했습니다. 합성 테스트 페이지에서 영상 전환 150ms 뒤 플레이어가 1배속으로 바꾸면, 수정 전에는 현재 배속과 저장 배속 모두 1이 되는 문제를 재현했습니다. 수정 후에는 둘 다 2배속을 유지했습니다.

- YouTube 방식 SPA 이동, `emptied`·`loadedmetadata`·`playing` 전후 초기화와 지연 초기화 복구.
- 팝업·단축키의 잠깐 1배속은 저장한 2배속을 바꾸지 않으며 다음 영상에서 2배속 복원.
- 명시적인 1배속 프리셋은 다음 영상의 배속으로 저장.
- 기본 플레이어 UI의 1.25배속·1배속 선택은 현재 영상에 반영하며 저장한 배속은 유지.
- 배속 유지 끄기 후 새 영상은 1배속, 다시 켜고 이동하면 저장해 둔 2배속 복원.
- 다른 사이트 전체 페이지 이동과 미디어 요소 교체 후에도 저장 배속 적용.
- 기존 확장·일반 사이트/임베드·팝업 브라우저 검사 모두 통과.

복구는 초기화/재생 시작 뒤 6초, 최대 20회로 제한합니다. 실제 YouTube 서버를 대상으로 이번 초기화 문제를 재현한 결과는 아니며, 아래 실제 사이트 확인은 각 항목의 명시 버전에서 수행한 이전 결과입니다.

## 검사 범위

- **단위 테스트 11개 통과**: 설정 마이그레이션, 배속 계산, 입력 제외, 도메인/URL 정규화, 하위 도메인 예외 경계, 미디어 선택 우선순위.
- **정적 검사 통과**: Manifest V3, 백그라운드 서비스 워커와 콘텐츠 스크립트 자산, JavaScript 문법, `storage`·`activeTab` 및 HTTP/HTTPS 접근 권한.
- **팝업 브라우저 검사 통과**: 연속 클릭 10회, 1배속 왕복, 즐겨찾기 저장·적용, 입력 범위, 빈 입력, 조절 간격, 단축키 안내 표시.
- **실제 확장 설치 검사 통과**: Chrome 156의 임시 일반 프로필에서 MV3 로드, 실제 Chrome storage/tabs 메시지, 실제 재생 가능한 무음 미디어를 사용.

확장 설치 검사에서는 다음 시나리오를 확인했습니다.

1. 기존 자동 모드 설정에서 수동 배속 값을 유지하고 새 설정으로 전환.
2. 팝업 연속 조절과 영상 위 버튼·프리셋·슬라이더의 즉시 반영.
3. 컨트롤 클릭이 영상 재생/일시정지를 건드리지 않음.
4. 단축키로 배속 조절 및 1배속↔직전 배속 전환, 전환키 반복 입력 방지.
5. 검색창·textarea·contenteditable·Shadow DOM 내부 입력란에서는 단축키 제외.
6. 단축키 끄기, 컨트롤 숨기기, 조절 간격 변경.
7. YouTube 기본 배속 변경과 같은 네이티브 `ratechange` 반영.
8. 광고 중 영상 배속 유지, 광고 중 선택한 배속을 본 영상에서 복구.
9. YouTube SPA 영상 전환 시 배속 유지 또는 1배속 초기화.
10. 다른 탭의 속도 변경이 기존 탭의 재생 속도에 영향을 주지 않음.
11. 전체화면에서 컨트롤 유지와 배속 변경.
12. 팝업 재오픈 후 설정 유지, 380×600 레이아웃, 자막 요청 없음.
13. 플레이어에 마우스를 올릴 때만 버튼 표시, 마우스 이탈 시 메뉴 닫힘, 키보드 포커스 접근성 유지.
14. 단축키 배속 알림 표시·자동 숨김·연속 입력 시 타이머 재시작, 버튼 표시를 끈 상태에서도 배속 알림 유지.

## 사이트 확장 / 예외 검사

`scripts/cross-site-check.cjs`를 실제 확장으로 실행해 다음을 통과했습니다. 테스트 도메인은 Playwright가 제공하는 고정 응답으로 구성하며 사용자 로그인이나 실제 사이트 응답을 흉내 내어 검증 결과로 섞지 않습니다.

1. YouTube 플레이어 ID가 없는 일반 HTML5 영상 제어와 상단/좌측 14px 위치.
2. 현재 사이트 스위치를 끄면 원래 배속 복구·버튼 제거·단축키 중지, 켜면 선택했던 배속 복원.
3. URL을 입력한 예외 추가, 하위 도메인 적용, 목록 해제 시 이미 열린 탭에 즉시 반영.
4. 다른 도메인 iframe의 영상으로 팝업 명령 전달, 부모 페이지의 단축키 전달.
5. 부모 사이트 예외와 임베드 제공 도메인 예외를 각각 적용하고 해제.
6. HTTP 오디오 전용 페이지의 배속 변경과 단축키.
7. 기존의 숨겨진/일시정지된 미디어와 새로 재생하는 미디어 사이에서 올바른 대상 선택.
8. 동적으로 추가한 열린 Shadow DOM 내부 영상 탐색.
9. 한 사이트의 조절·예외 설정이 다른 탭의 재생 중인 속도를 임의로 변경하지 않음.

## 실제 일반 웹사이트 확인

v0.3.0을 로그인하지 않은 임시 Chrome에 로드하고 공개 페이지 `https://www.w3schools.com/html/html5_video.asp`를 확인했습니다. 팝업에서 1.5배를 선택했을 때 페이지의 두 영상 중 대상 하나만 **1.5배**, 다른 하나는 **1배**를 유지했습니다. 현재 사이트 예외를 켜면 대상 영상의 원래 배속이 복구되는 것도 확인했습니다.

## 실제 YouTube 확인

아래 기본 배속 조절은 v0.2.0에서 확인한 결과입니다. 최신 버전의 기존 YouTube 동작은 위 실제 확장 설치 검사에서 검증했습니다.

로그인하지 않은 임시 Chrome에서 공개 영상 **Sleep Is Your Superpower | Matt Walker | TED** (`5MuIMqhT8DM`)을 열었습니다.

광고 종료 후 영상 위 프리셋으로 **1.5배**, `+` 버튼으로 **1.6배**, `]` 단축키로 **1.7배**, `\`로 **1배 → 1.7배** 전환을 확인했습니다. 팝업에도 **1.70배**가 표시되었습니다. 마지막 상태는 재생 중이며 광고가 아니었습니다.

이 검사는 자막 분석이나 자막 엔드포인트에 의존하지 않습니다. 모든 영상·브라우저 조합의 호환성을 보장하는 결과는 아니며, 실제 스크린리더 장비를 통한 별도 사용성 검사는 수행하지 않았습니다.

## 검증 환경

사용자의 Chrome 프로필·로그인 계정은 사용하지 않았습니다. 검사에 사용한 임시 프로필은 종료 시 삭제했습니다. `extension-popup.png`는 실제로 로드한 확장의 화면이고, `player-controls.png`와 `shortcut-feedback.png`는 명시적인 테스트 영상 페이지의 컨트롤과 단축키 알림 화면입니다.
